# @enterprise/localization

Enterprise Localization and Internationalization system based on i18next, react-i18next, and native Intl formatters.

## Capabilities
- Supported Locales: `vi-VN` (default), `en-US` (fallback)
- Strongly typed translation keys and symmetry governance
- Native `Intl` number, currency, date, time, and relative formatters
- Lazy namespace loader per application route
- Document `lang` & `dir` automatic DOM synchronization
